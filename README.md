Calculadora Beaga Semijoias

Uma aplicação web simples e direta desenvolvida para facilitar cálculos e agilizar o dia a dia.

Como acessar
A calculadora está hospedada online e pode ser usada em qualquer computador ou celular.
(https://fisicacomfabao.github.io/Beaga-semijoias/)

Tecnologias Utilizadas
HTML5: Estrutura da página.
CSS3: Estilização e layout visual.
JavaScript: Lógica matemática e funcionamento dos botões.

Como funciona
1. Acesse o link acima.
2. Insira os valores necessários nos campos indicados.
3. O resultado será calculado automaticamente na tela.
